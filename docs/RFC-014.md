RFC-014
Search API & External Contract (SSOT Interface)

**상위·정합 문서**

- `RFC-000: Wine Intelligence Engine Master Architecture.md` — Query API → Planner → … → Response; **LLM은 explanation만·never authority**
- `RFC-008` — **`SearchResponseV1`·`EngineDecision`·`evidence_items`** 필드 SSOT — 이 RFC의 JSON은 **RFC-008과 모순 없이** 매핑해야 한다
- `RFC-005` — `QueryPlanV1` (`/interpret` 응답 형태)
- `RFC-007` — `DecisionOutput` → `engine_decision` 매핑
- `RFC-015` — **`decision_snapshot`**, **`POST /v1/search/replay`**
- `RFC-016` — **`failure_reason`·`admission_trace_ref`** — 외부 계약 필드; replay snapshot 무결성 실패 시 **error contract**

**충돌 시 RFC-008·RFC-000 우선.**

0. 목적

이 시스템은 단순 API가 아니다.

UI가 붙는다
LLM agent가 붙는다
외부 파트너가 붙는다

즉:

모든 소비자가 동일한 의미로 결과를 해석하도록 만드는 계약이 필요하다

한 줄:

API는 데이터 전달이 아니라, Decision + Evidence를 전달하는 인터페이스다

4.3 Replay (RFC-015)

**`POST /v1/search/replay`** — 과거 응답과 **동일 스냅샷**으로 재실행. 디버깅·회귀·고객 이슈 재현.

Deprecated field lifecycle과 consumer migration 상태는 [Wave 4 Deprecated-Field Migration Guide](/Users/songmin/wine-search-engine/docs/bugbash/apr-6-hardening-wave4-migration-guide.md)를 따른다. Support/oncall triage는 [Wave 4 Ops Runbook](/Users/songmin/wine-search-engine/docs/bugbash/apr-6-hardening-wave4-ops-runbook.md)을 기준으로 한다.

**Request (필수):** `query`, **`decision_snapshot`**(이전 `/v1/search` 응답의 `engine_decision.decision_snapshot`과 동일 구조), `context`·`options`·`session_context`·`query_budget`(선택).

**Snapshot integrity (fail-closed):** Replay는 요청에 담긴 `decision_snapshot`과 **현재 런타임이 사용하는 snapshot refs**(예: `index_versions.retrieval_index_version`, `planner_version`, `policy_rule_version`, `threshold_profile_id` — RFC-015·RFC-016과 정합)가 **일치할 때만** 성공으로 간주한다.

**불일치 시:**

- **HTTP error contract**를 반환한다 — 정상 `SearchResponseV1`로 “성공한 replay”를 **가장하면 안 된다**.
- 응답 body의 기계 판별 가능한 **`reason` = `SNAPSHOT_MISMATCH`**(RFC-016 `FailureReason`과 동일 코드)를 포함한다.
- **silent fallback replay 금지** — 스냅샷을 무시하고 현재 인덱스·정책으로 돌려 결과를 주는 동작은 금지한다.

**Error contract 예시 (필드명은 팀이 `api_version`에 맞게 고정):**

```json
{
  "error": {
    "code": "SNAPSHOT_MISMATCH",
    "message": "decision_snapshot does not match current runtime snapshot refs",
    "failure_reason": "SNAPSHOT_MISMATCH",
    "request_id": "req_…",
    "retryable": false
  }
}
```

**Response (성공 시):** 일반 `SearchResponseV1`과 동일 스키마. 바이트 동일 재현은 인프라가 고정할 때만 보장; 그 외는 RFC-009 §12.5 tolerance.

11. Versioning
/v1/
/v2/

breaking change 시:

필드 제거 금지
optional 추가만 허용
enum 변경은 **additive only**

deprecated field는 최소 한 버전 윈도우 동안 유지하고, replay/debug 경로와 함께 제거 계획을 문서화

11.1 Extensibility principle

새 retrieval source, 새 reranker, 새 planner heuristic이 들어와도 **외부 contract 의미**는 바뀌지 않는다.

- 내부 실험은 `decision_snapshot.feature_flags`·version field로 surface한다.
- 외부 소비자는 **`decision_status` / `next_action` / `evidence_items` / `decision_snapshot`** 만으로 일관되게 해석 가능해야 한다.
- 즉 API는 모델 카탈로그가 아니라 **의미 계약**을 안정적으로 제공해야 한다.
